# The site's fonts

These are modified versions of two fonts under the SIL Open Font License 1.1,
cut down by `scripts/font.ts` to the characters the site sets.

- `site-mono-regular.woff2`, `site-mono-bold.woff2` and `site-mono-italic.woff2`
  are named **Rockaway Mono Site Subset**. They are derived from IBM Plex Mono,
  Copyright © 2017 IBM Corp. with Reserved Font Name "Plex". Because they are
  modified, they do not carry that name. Licence: `OFL-plex-mono.txt`.
- `site-symbols.woff2` is named **Rockaway Mono Site Symbols**. It is derived
  from JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors.
  Licence: `OFL-jetbrains-mono.txt`.

Each face keeps its original copyright, version and licence in its own name
table. `site-mono.json` records the pinned sources, the metrics and the
character ranges.
