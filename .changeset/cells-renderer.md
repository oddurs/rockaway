Render painted cells through one component, `Cells`: a screen's chrome, a list's scrollbar and a tree row's guides. It takes `inline` for one row set in a line of text and `colours={false}` where the stylesheet colours the cells by state. It replaces `Chrome` and `chromeRows`, which came in with server-rendered chrome and have not been released.
