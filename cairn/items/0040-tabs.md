## Purpose

Switch between views that share one place: `files`, `log`, `diff`. Not for
navigation between pages (links), and not for steps in a sequence.

## Anatomy

`<Tabs>`, `<TabList>`, `<Tab id>` and `<TabPanel id>`, on React Aria's. `Tabs`
is React Aria's `Tabs` around a `Screen`.

- **Frame.** The frame is painted by `tabsBuffer`. It leaves a gap in its top
  edge for each tab, a cell of line between two tabs, and the theme's overflow
  marks at the ends when the tabs scroll: `┌ files ─ log ─ diff ─────┐`.
- **Tabs.** Each tab is React Aria's element laid over its gap: its label with a
  cell of air either side. Labels are measured in cells from the page.
- **Laying out.** `layoutTabs` is pure. When the tabs do not fit, it chooses
  the earliest run of whole tabs that still shows the selected one.
- **Scrolled out of the edge.** A tab out of the edge keeps its element, so the
  keyboard reaches it and a reader hears it, but it takes no cells and is not
  seen.
- **Panels.** A panel fills the frame inside its border and padding, in whole
  cells.
- **Placing a tab.** React Aria renders a tab from its collection, not from
  the `Tab` function. So the part that reads the frame (`TabCells`) is a
  component inside the tab, and it writes the tab's cells on the tab element
  as custom properties.
- **Snapshot.** `tabsText` draws the labels into the frame, for the snapshot.

## States

From React Aria's attributes, drawn as 0118 says:
- **Selected:** reverse video, the tab's own figure and ground swapped, and
  bold. In forced colors the tab opts out of the backplate and swaps
  `CanvasText` and `Canvas`.
- **Hover:** underlines the label.
- **Disabled:** dim.
- **Focus:** the ring.

No state changes a tab's cells. Vertical orientation is not built: a vertical
tab list belongs in the frame's side edge, which is a ticket of its own.

## Tokens consumed

`border.default` for the frame, `fg.muted` for the overflow marks and
unselected tabs, `fg.default` and `bg.page` swapped for the selected tab, and
`fg.disabled`. The ticket named `bg.inverse` and `fg.on-inverse`; they are not
used, because forced colors maps that pair to the canvas (0181).

## Accessibility

`tablist`, `tab` and `tabpanel` through React Aria: arrows move between tabs,
Home and End jump, activation automatic by default and manual by prop. The
frame and the overflow marks are `aria-hidden`.

## 2026-10-03

React Aria builds a tab list's collection in a hidden pass and then renders each tab from the collection, not from our Tab function. So a Tab wrapper that read the frame's layout from context saw no frame, and the tabs never moved. TabCells is a component inside React Aria's tab: it reads the frame, measures the label, and writes --rk-tab-x/cols on the tab element. The screenshot tool also needed to skip the hidden <template> React Aria leaves in the DOM.

## 2026-10-03

Overflow: layoutTabs picks the earliest run of whole tabs that still shows the selected one, with the theme's overflow marks (‹ ›, or < > under ASCII) and a cell of line inside each. A test walks widths 12 to 60 and every selection, and the story arrows through seven tabs in 28 cells, checking each one comes into view. The window is stateless, so moving back from the last tab jumps to the earliest run that holds the new one rather than sliding by one. Tabs out of the edge keep their elements (the keyboard and a reader reach them) but take 0 cells and opacity 0. Without that, axe measured the clipped label's contrast against whatever was under it.

## 2026-10-03

Under manual activation, focus can move to a tab out of the edge without selecting it, and that tab stays unseen until it is selected. Showing the focused tab as well as the selected one needs the focused key from React Aria's state; it's a small follow-up if manual activation with many tabs matters. Selected uses the tab's own pair swapped plus bold, not bg.inverse, after 0181.

## Result

Tabs on React Aria, with the tab list in the panel frame's top edge, a cell of line between tabs. Selected is reverse and bold via the tab's own pair, kept in forced colors. Overflow scrolls by whole tabs with the theme's marks and always shows the selected tab. The panel fills the frame in whole cells. Vertical tabs are not built.
