## Purpose

A hierarchy you can expand and collapse: a file tree, and the site's
navigation. Rows behave like List rows (cursor, reverse-video selection,
type-ahead); depth is drawn with tree guides (`├─ └─ │`) from the junction
table, so the guides are geometry, not text. Not for flat collections (List)
or menus (Menu).

## Anatomy

`<Tree>` and `<TreeItem title>` on React Aria's `Tree`. Each row: guides, the
expand mark, the cursor cell, the label. Items may be links (`href`), which is
how the site's navigation pane uses it.

## States

`data-expanded`, `data-focused`, `data-selected`, `data-disabled`, `data-level`.

## Tokens consumed

`fg.default`, `fg.muted` for guides, `bg.inverse` / `fg.on-inverse` for selection.

## Accessibility

`treegrid` semantics from React Aria: arrows move, right expands, left
collapses or moves to the parent, type-ahead, Home and End. Guides and marks
are `aria-hidden`; level, expanded state and position in set are announced by
the role.

- [ ] Indentation is whole cells per level, and a long label truncates with `…` without breaking the guides
- [ ] Link items navigate on Enter and on press, and expand marks do not
