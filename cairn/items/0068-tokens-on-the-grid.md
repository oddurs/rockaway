The token pipeline survives the pivot; its contents do not.

Radius, shadow and the type scale go. Cell metrics, glyph sets, attributes and
an ANSI-16 palette arrive. The generator, the resolver, the contrast gate and
the CSS layers stay exactly as they are.

## 2026-09-23

Done 2026-09-23, ahead of the 2026-12-20 due date. The pipeline is unchanged and its contents are new: an ANSI 16 palette generated in OKLCH with role slots beside it, cells and density as the line box, glyphs and attributes as tokens, radius and shadow and the type scale retired, the CSS layers rewritten for the grid, terminal themes exported for four terminals, and a reference that documents what exists.
