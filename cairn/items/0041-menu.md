## Purpose

A list of actions opened from a trigger: the context menu, the `⋯` button, a
menubar's menus. Not for choosing a value that persists (Select), and not for
navigation (links in a Tree or List).

## Anatomy

`<MenuTrigger>`, `<Menu>`, `<MenuItem>`, `<MenuSection title>`,
`<MenuSeparator>`, `<SubmenuTrigger>` on React Aria, inside a Popover (0034).
Rows share List's drawing (the cursor cell, reverse video for the focused
row). Shortcuts are KeyHints right-aligned in the row. A separator is a rule
that joins the popover's frame (`├───┤`) through the junction table; a
section title is set into that rule.

## States

`data-focused`, `data-hovered`, `data-pressed`, `data-disabled`, `data-selected` (checkable items), `data-has-submenu`, `data-open`.

## Tokens consumed

`bg.surface`, `fg.default`, `bg.inverse`, `fg.on-inverse`, `fg.muted` (shortcuts), `fg.disabled`.

## Accessibility

`menu`, `menuitem`, `menuitemcheckbox` and `menuitemradio` through React Aria:
arrows move, Enter and Space activate, type-ahead, Escape closes, right opens
a submenu and left closes it. Shortcuts are announced through
`aria-keyshortcuts`, not read as glyphs.

## 2026-10-03

Built on Popover with padding {0,0}, so a row runs from side to side of the frame and the cursor's reverse video is a bar across it. Separators and section titles are rows the content leaves empty (a title's text is visibility: hidden, still the group's name); Menu measures their rows off the page and hands them to the surface as dividers, which overlayBuffer draws as light rules joining the heavy sides through the junction table. Measured beside the menu, not in it: measureCell appends a probe, which inside the observed menu is a mutation, and the first version spun the renderer at 250% CPU for ever.

## 2026-10-03

Rows are drawn by a Row component inside React Aria's item render, because the collection renders items from itself: the check cell's context and aria-keyshortcuts (filtered from props) are only reachable there. Submenus take shift {main: 1, cross: -1} from #149: past the parent's frame, and up to its border so the first item is on the opener's row; React Aria mirrors it on a flip. Found and fixed a contract bug on the way: OverlayPopover sent submenus to the layer, outside their root popover, whose focus scope then took focus back to body. A nested popover now keeps React Aria's own container, which is inside the layer anyway.
