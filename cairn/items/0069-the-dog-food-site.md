A website built out of the system it documents, which is the only honest way
to show a TUI system for the web.

It has to be fast, keyboard-first, readable on a phone, and good enough that
somebody who came for the screenshot stays for the docs.

## 2026-10-03

Program plan (2026-10-03). The scaffold (0103) starts in wave 1, as soon as the package exports are right (0121), so the site dog-foods components as they land; deploying (0146) waits only on the owner enabling Pages (0145). Prose on the grid (0143) and the budget (0109) follow in waves 2 and 3, so every later page is held to both. The shell (0104) needs Panes, Tree, StatusBar, Link, the keymap and server-painted chrome; the palette joins it through 0149 rather than blocking it. Content (component pages 0147, foundations 0106, getting started 0107, theme switching 0148, example apps 0151, the landing page 0108) is wave 5, and the end-to-end review (0152) closes the milestone.
