## Purpose

Navigation to another page or place: in prose, in a status bar, in a list of
pages. Not for actions that change state (that is Button), and not styled as a
button.

## Anatomy

`<Link href>` on React Aria's `Link`. Inline text; no chrome, no frame.

## States

`data-hovered`, `data-focus-visible`, `data-pressed`, `data-current` (from
`aria-current`), `data-disabled`.

## Tokens consumed

`fg.accent` for the text, `fg.default` when current. Underline from the attribute tokens.

## Accessibility

Native link semantics. A link is always underlined, not only on hover, so it
is distinguishable without colour (WCAG 1.4.1). `aria-current="page"` draws
bold plus the cursor mark per 0118. An external link carries a mark that is
`aria-hidden` and a visually hidden "(opens in a new tab)" only when it does.

## 2026-10-03

The cursor mark for current hangs in the cell before the link: an aria-hidden span, absolutely positioned at the link's start and stepped back one cell with margin-inline-start, so it is out of flow and the link costs the same cells in every state. That cell belongs to the layout, which leaves it blank — the word space in prose, the gap in a row of links — so the mark replaces a space the way a terminal draws it. The Current story proves nothing after a link moves when it becomes current. A reserved cell inside the link was the alternative, and would have put a space before every link in every sentence.

## 2026-10-03

Hover cannot be 0118's underline, because a link is underlined at rest (WCAG 1.4.1). It doubles the underline instead (text-decoration-style: double), which is a terminal attribute too (SGR 4:2). Pressed is reverse video built from the link's own colour — background: the link's fg, colour: bg.page — rather than bg.inverse, which is the truest swap and is what survives forced colors: there it is LinkText behind Canvas text, asserted in the forced-colors browser. bg.inverse would collapse to Canvas on Canvas.

## 2026-10-03

No variants: the ticket declares none, so there is nothing for defineVariants to hold. Opening a new tab is not a state or a variant but a fact of the target (target="_blank"): it adds the theme's mark.external as a cell of the link's own (an inline-block, so the underline stops before it) and a VisuallyHidden '(opens in a new tab)', overridable with newTabLabel. Both marks come from useGlyphs() (0119 merged mid-ticket; the first cut drew them from the CSS glyph tokens with content:, and was rebuilt as text nodes to match List and Button).

## 2026-10-03

linkBuffer(label, state, glyphs) is the text snapshot: cell 0 is the cell before the link, then the label, then the external mark. Hover and focus are not cell attributes (a doubled underline, an outline around the cells), so they print as rest, which is the point. The States story checks the stylesheet against linkStyle() — colour token and weight per state — so the snapshot and the CSS cannot drift apart silently.

## 2026-10-03

Touch: at touch density the row is two lines tall (asserted >= 32px) and links in a row sit two cells apart, so neighbouring targets do not crowd; a link inside a sentence keeps the inline box's height, which WCAG 2.5.8 exempts. Forced colors: apps/workbench/vitest.config.ts now selects the forced-colors browser by the 'forced-colors' story tag instead of the ForcedColors.stories.tsx file name, so a component keeps its forced-colors story beside its others; the foundations story carries the tag.
