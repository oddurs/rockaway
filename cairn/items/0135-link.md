## Purpose

Navigation to another page or place: in prose, in a status bar, in a list of
pages. Not for actions that change state (that is Button), and not styled as a
button.

## Anatomy

`<Link href>` on React Aria's `Link`. Inline text; no chrome, no frame.

## States

`data-hovered`, `data-focus-visible`, `data-pressed`, `data-current` (from
`aria-current`), `data-disabled`.

## Tokens consumed

`fg.accent` for the text, `fg.default` when current. Underline from the attribute tokens.

## Accessibility

Native link semantics. A link is always underlined, not only on hover, so it
is distinguishable without colour (WCAG 1.4.1). `aria-current="page"` draws
bold plus the cursor mark per 0118. An external link carries a mark that is
`aria-hidden` and a visually hidden "(opens in a new tab)" only when it does.
