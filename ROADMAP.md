# rockaway — Roadmap

A TUI design system for the web: everything on a character grid.

A TUI design system for the web. Four contracts, kept apart on purpose:

| Contract | What it holds | Built on |
| --- | --- | --- |
| **Grid** | Integer cell geometry: boxes, junctions, text measurement, layout, painters | `@rockaway/grid`, no DOM |
| **Tokens** | Design decisions as data: ANSI palette, cell metrics, glyph sets, attributes | DTCG 2025.10 and its Resolver |
| **Behaviour** | Accessibility, focus, keyboard and state. No styling | React Aria Components |
| **Style** | CSS that reads semantic tokens and `data-*` state, and nothing else | Custom properties, cascade layers |

Everything is a whole number of cells, unless it declares otherwise and says
why. Strictness is a dial, not a law: `strict`, `standard` or `loose`.
