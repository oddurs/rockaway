## Attributes

Variants, and the states each component draws.

- Badge: `data-tone` (neutral, accent, success, warning, danger)

- Button: `data-variant` (default, fill, danger), `[data-hovered]`, `:focus-visible`, `[data-focus-visible]`, `[data-pressed]`, `[data-disabled]`

- Callout: `data-tone` (note, tip, warning, danger)

- Divider: none

- Fieldset: `data-kind` (control, group), `[data-invalid]`, `[data-disabled]`, `[data-focus-visible]`

- Form: `[data-required]`, `[data-disabled]`

- Frame: none

- KeyHint: none

- Link: `[data-hovered]`, `:focus-visible`, `[data-focus-visible]`, `[data-pressed]`, `[aria-current]`, `[data-current]`, `[data-disabled]`

- List: `[data-hovered]`, `[data-focused]`, `[data-selected]`, `[data-disabled]`

- Tree: `[data-hovered]`, `[data-focused]`, `[data-selected]`, `[data-expanded]`, `[data-disabled]`
